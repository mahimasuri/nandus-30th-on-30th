# LEVEL 30 — NANDU v2

Premium retro music-player birthday game for Abhinandan (Nandu).

## v2 changes
- CD/vinyl player is now the core visual language.
- Play / pause, previous / next, shuffle and repeat controls.
- Animated record + waveform.
- Interactive Bulls & Cows keypad.
- Every guessed digit is individually marked Bull / Cow / Miss.
- Random Nandu Database photo popups using the 15 supplied photos.
- Theme is centralized in `config.js` and easy to change.
- No copyrighted audio files are bundled; music controls can open the selected track in YouTube search so music can be audible without bundling copyrighted audio files. A small browser interaction tone is also included.

## Run
Open `index.html` in a browser. For the smoothest local experience, serve the folder with any simple static server.

## Customize
Edit `config.js` for theme colors, songs and photo list.
Edit `game.js` for questions, captions and computer dialogue.
